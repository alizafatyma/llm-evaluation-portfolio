LLM Evaluation Lab

A side-by-side human evaluation of two AI models on 12 tasks covering coding, reasoning, instruction following, English–Urdu language ability, and safety, scored against a written rubric.

Setup

Paste each prompt into both models in a fresh chat, copy their full replies below, then score them. Work saves automatically in this browser.

    Key findings

    Method

    Each task is sent to both models in a fresh conversation with no system prompt and no follow-up. Every response is scored independently on five dimensions (1–5), tagged with any errors, and then the two responses are compared on a 7-point preference scale with a written justification. Each task has reference notes written before collecting responses, listing what a strong answer must include and the common failure modes, so scoring is consistent and not influenced by which answer "sounds" better.

    Writing a good justification

    • Lead with the deciding factor: "B is better because A's SQL query groups by name, which merges different customers who share a name."
    • Be specific and verifiable: quote the wrong line or the missed constraint. Avoid "A is more detailed".
    • Correctness beats style. A short correct answer is better than a long, polished, wrong one.
    • Check the facts yourself (run the code, do the maths, look up the claim) instead of trusting either model.
    • Penalise over-refusal as well as unsafe help: refusing a harmless request is a failure too.
